DSH 插件市场

为 DSH 文件工作台精选的三件装备。一条命令装进 profile，编辑器右侧工作台的「扩展」入口即刻多一格能力。

纯 JS 单文件插件宿主 HTTP API 全开放容器已托管 dsh
bash — ~/.dsh/fileworkbench
$ dsh plugin --profile web add <package>
added 1 package in 3s · cordis discover ✓
✓ 重启工作台后在「扩展」里启用
⚡ 免编译直装插件是纯 JS 单文件，导入即打包激活，无需 node_modules 地狱。
🔌 贡献点体系侧栏视图 / 状态栏 / 「扩展」气泡菜单 / 编辑器装饰，一处 register 全接管。
🛠️ 容器托管顶栏「应用 › DSH」面板可直接对 profile 安装 / 更新插件。

📦 精选插件

点「复制」拿到安装命令，粘贴到终端执行即可。

01 Prompt 库

dsh-prompt-library

DSH 提示词库插件：沉淀、检索并一键注入常用 Prompt，配合 profile 持久化共享团队模板。

dsh plugin --profile web add @sunjuntao/dsh-prompt-library
github.com/master1Sun/dsh-prompt-library ↗
02 文件工作台

dsh-file-workbench-lib

DSH 文件工作台本体：右侧文件树 + 仿 VS Code 编辑器，开放外部插件注入 API（侧栏视图、状态栏、编辑器装饰、宿主 HTTP API）。

dsh plugin --profile web add @sunjuntao/dsh-file-workbench
github.com/master1Sun/dsh-file-workbench-lib ↗
03 QQ 机器人

dsh-QQbot

DSH × QQ 机器人桥接插件：把 dsh 会话接入 QQ 频道，消息驱动任务并在群里回收结果。

dsh plugin --profile web add @sunjuntao/dsh-qqbot
github.com/master1Sun/dsh-QQbot ↗
